# Matplotlib Property Viewer

A GUI tool for viewing and editing Matplotlib plot properties.

## Features

* View and edit Matplotlib plot properties through a GUI
* Support multiple plot types
* Modify plot properties such as markers, lines, axes, and labels
* Apply property changes to the plot interactively

## Requirements

* Python 3
* NumPy
* Matplotlib
* PySide6

## Status

This project is currently under development.

The API and class structure may change in future releases.
